03 — A vs B at a glance

Direction A · Soft Emerald

  • Mood: calm product / wellness
  • Accent: soft emerald green
  • Surfaces: blue-slate cards, soft radius
  • Tabs: floating frosted pill
  • Start: filled circle button
  • Metrics: 2×2 soft tiles

Direction B · Athletic HUD

  • Mood: sport watch / race day
  • Accent: volt lime on pure black
  • Surfaces: flat panels, tight radius
  • Tabs: solid edge dock
  • Start: readiness ring + GO
  • Metrics: stacked HUD rows + mono type
