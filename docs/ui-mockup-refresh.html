3. What changes vs what stays

Usability guardrails: no smaller tap targets, no light mode forced outdoors, no hiding Finish behind menus.

Keep Usability & visibility

  • Dark base — dawn / gym friendly, high contrast text
  • Tabular numbers — clock and pace don’t jitter
  • Large primary metrics — glanceable mid-run
  • Full-width Pause / Finish — no accidental tiny targets
  • Five tabs, local-first — same IA and no social feed
  • Green accent — readable in sun; zone colors stay distinct

Refresh Fresh & modern

  • Design tokens — deeper bg, softer borders, elevation glow on primary
  • Floating tab bar — pill + blur + stroke icons (not mixed glyphs)
  • Hero Start — circular CTA above the fold on ready screen
  • Folded setup — goal/workout/shoes collapse so sensors stay visible
  • Card hierarchy — uppercase micro-labels, less equal “every card is H2”
  • History rows — date badge + calmer meta line + optional HR strip

4. Suggested implementation order

PR 1 — Tokens + chrome

:root colors, radius, card borders, floating tab bar, SVG icons. Zero flow changes. Safe to ship alone.

PR 2 — Run hierarchy

Hero Start block, segmented Outdoor/Treadmill, collapsible setup cards. Keep arm → start semantics.

PR 3 — Live metrics polish

Bigger hero, goal track styling, dual Pause/Finish weights, map slot height tune.

PR 4 — History + Coach polish

List date badges, filter chip bar, calendar cell styles, recovery + next-session hero on Coach.
